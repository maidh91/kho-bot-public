# KHO Bot public research

[Open the interactive report](https://maidh91.github.io/kho-bot-public/).

This is a small public summary of the November 2026 historical research campaign. It shows three preset objectives and fifteen representative results. Select any result for rounded monthly equity, month-end drawdown and rolling 36-month charts, yearly and monthly returns, and closed trade count. Charts can show the full period or latest decade. The page also explains cost sensitivity and model limits. It is self-contained and opens locally as [index.html](index.html).

The complete research library and exact strategy settings are private. This repository intentionally contains no parameter files, trade journals, broker data, source or input hashes, or raw market history. Results are rounded and detailed charts use month-end summaries. Month-end drawdown can understate the full-path maximum. The historical search used all shown periods; this report is not a forward test or a live trading recommendation.

Before publishing an update, generate a fresh public summary from an explicit list of allowed aggregate fields, review the resulting HTML itself, and check the complete Git diff and history for embedded private data. Never copy an HTML report from the private research library directly: its compressed payload includes exact configurations.
